# Argus site

Landing page for [Argus](https://github.com/ruanjkz/argus), an open source server manager for FiveM. Built with Next.js, Tailwind and shadcn/ui.

The Argus panel itself lives in the main repository and runs locally on each server. This repository is only the public website.

## Development

```bash
npm install
npm run dev
```
